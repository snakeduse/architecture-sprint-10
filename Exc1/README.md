# Аудит мер по обеспечению безопасности данных и улучшения по защите данных

## Аудит мер по обеспечению безопасности данных

- У таких сотрудников, как врачи, администраторы нет ограничений на работу с файлами-журналами пациентов. Сотрудники могут просматривать, удалять и изменять любые данные;
- Отсутствует аутентификация при доступе в данным пациентов;
- Отсутствует разделение данных на категории;
- Отсутствует резервное копирование данных;
- Отсутствуют механизмы защиты чувствительных данных, такие как шифрование, обфускация, обезличивание;
- Отсутствует контроль потоков данных между IT-продуктами;
- Данные хранятся в файлах, а не специальных системах хранения данных;
- Файлы с данными пациентов хранятся в открытом виде;
- ККМ взаимодействует с сервером по открытому протоколу.

## Улучшения по защите данных

Предлагаются следующие улучшения по защите данных:

- Необходимо разделить данные на следующие категории:
  - Personally Identifiable Information:
    - Ф. И. О.;
    - Дата рождения;
    - Телефон;
    - Электронная почта;
    - Адрес прописки;
    - Место работы или учёбы;
  - Protected health information:
    - Хронические заболевания;
    - История болезни пациента;
  - Protected finance information:
    - Оплата;
    - ТМЦ;
- Необходимо добавить согласие на обработку персональных данных при регистрации новых пациентов в системе;
- Необходимо настроить шифрование дисков, на которых хранятся Excel-файлы;
- Необходимо перевести продукты 1С с файлов на клиент-серверную архитектуру, с работой по защищенному протоколу TLS версией 1.2 и выше;
- Необходимо перевести взаимодействие ККМ с сервером через протокол TLS версии 1.2 и выше;
- Необходимо настроить ролевое разграничение доступа к файлам и директориям;
- Обезличить информацию о пациентах при работе с бухгалтерией, например, использованием уникального идентификатора пациента вместо телефона, Ф.И.О. и даты рождения;
- Необходимо настроить резервное копирование данных;
- Необходимо шифровать потоки данных между внутренними IT-продуктами;
- Необходимо заложить возможность замены работы с файлами на работу со специализированными IT-системами;
- Необходимо вести аудит работы системы.
